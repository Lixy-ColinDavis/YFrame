# YFrame

YF软件框架，基于C#.NET8.0，WPF开发，采用MVVM框架，仿VS界面风格设计，动态灵活加载各插件，可根据需求自定义添加和修改插件，持续开发中...如发现此项目，欢迎点评指导！(20250819)

### 主框架功能列表

1. CPU内存性能监视器

2. 全局Log同步监控

3. 全局主题切换

4. 多语言系统

### 已开发插件：（代码尚未整合）

1. AI对话助手本地部署

2. OCR屏幕语言一键截屏翻译

3. HTTP文件服务器一键部署
